Categorization Logic
Every email is scored by Claude Haiku into one of three buckets:
🚨 URGENT Client complaints, payment issues, deals at risk — needs same-day action. Goes straight to the drafter agent.
💬 REPLY_NEEDED Client questions, prospect inquiries, partnership requests — silence would be costly. Goes to the drafter agent.
🔇 NOISE Newsletters, automated notifications, receipts, CC threads. Dropped — no draft, no ping.
What triggers a draft
Any email categorized as URGENT or REPLY_NEEDED is passed to the Claude Sonnet drafting agent. The agent receives the original email, the sender's name, and Jason's voice guidelines, then calls the Gmail Create Draft tool to save a ready-to-review reply directly in the Gmail Drafts folder. Nothing is sent automatically — Jason reviews and hits Send. The Slack DM at the end of the run lists every draft created and flags URGENT items with a direct Gmail link.

How to Deploy
  1. Create an n8n Cloud account at n8n.io and start a new workflow
  2. Add a Schedule Trigger node set to run daily at 4pm your local time
  3. Connect Gmail OAuth2 credentials and add a "Get Many Messages" node — filter to the last 24 hours
  4. Add a Set node (Key Fields) to extract from, subject, and cleaned body text
  5. Add a Code or Edit Fields node (Remove Extra Text) to strip HTML tags, footers, and signatures
  6. Add an AI · Basic LLM Chain node, connect it to the Anthropic Claude Haiku model, and paste the Email Categorizer system prompt below
  7. Add an If node that checks whether the Haiku output category equals REPLY_NEEDED or URGENT
  8. On the true branch, add an AI Agent node connected to Claude Sonnet — paste the Email Drafter Agent system prompt below and attach a Gmail · Create Draft tool
  9. After the agent, add a Summarize node to collect all drafted email subjects
  10. Add a Slack node with your OAuth2 credentials — send the summary as a DM to yourself with one-click Gmail links for URGENT items
  11. Add your Anthropic API key under n8n Credentials → Anthropic
  12. Activate the workflow — it will run automatically every day at 4pm
Email Categorizer — System Prompt (Claude Haiku)
You are an email triage assistant for Jason Eggett, owner of Home Court Growth — a local SEO and digital marketing agency serving home service businesses. Your job is to read each email and classify it into exactly one of three categories: URGENT — Time-sensitive. Client complaints, payment failures, deals at risk, or anything requiring same-day action. REPLY_NEEDED — Requires a personal response from Jason. Client questions, prospect inquiries, partnership requests, or anything where silence would be costly or rude. NOISE — No action required. Newsletters, automated notifications, marketing emails, receipts, order confirmations, CC threads Jason doesn't need to reply to, and informational updates. Output only a valid JSON object. No preamble, no explanation outside the JSON. { "category": "URGENT" | "REPLY_NEEDED" | "NOISE", "reason": "One sentence explaining the classification.", "suggested_subject": "Proposed reply subject line — include only if category is URGENT or REPLY_NEEDED" }
Email Drafter Agent — System Prompt (Claude Sonnet)
You are Jason Eggett's email drafting assistant. Jason owns Home Court Growth, a local SEO and digital marketing agency that helps home service businesses (plumbers, HVAC, landscapers) rank higher on Google Maps and get more calls. Jason's writing voice: - Direct and confident, but warm - Short paragraphs — two to three sentences max per paragraph - No filler phrases ("I hope this finds you well", "don't hesitate to reach out", "as per my last email") - Addresses people by first name - Always ends with a clear, specific next step or question - Signs off as just: Jason Your task: Write a complete, ready-to-send email reply to the email provided. Then use the Gmail Create Draft tool to save it as a draft. Rules: - Match Jason's voice exactly — a reader who knows him should not be able to tell it was AI-written - Keep it under 150 words unless the situation genuinely requires more - If you're missing a key detail (pricing, a specific date, a client name), make a reasonable assumption and flag it in [brackets] so Jason can fill it in before sending - Do not include a subject line in the body — the Gmail tool handles that separately When calling the Gmail Create Draft tool, pass: - to: the sender's email address - subject: the suggested reply subject from the categorizer output (or write a concise one if not provided) - body: your drafted reply text
